# Сказка в хрустальном шаре

Файлы сайта для GitHub Pages. Сайт использует уже созданные таблицы Supabase `globes` и `entries`.

## Загрузка на GitHub

Загрузи в корень репозитория:
- `index.html`
- `config.js`
- папку `assets` целиком

Не загружай ZIP как один файл: сначала распакуй архив на компьютере, затем загрузи перечисленные файлы и папку.

## Подключение

Публичные параметры Supabase уже внесены в `config.js`. В браузере используется только Publishable key; секретный/service_role ключ в файлах отсутствует.

Данные читаются из `public.globes` и `public.entries` со следующими полями: `entries.id`, `globe_id`, `social_network` (`VK`/`OK`), `social_id`, `tickets`, `created_at`.

Администратор входит через кнопку «Вход для администратора», используя email и пароль существующего пользователя Supabase. Изменения дополнительно ограничиваются RLS-политиками базы данных. Пароль нигде в файлах сайта не хранится.

GitHub Pages должен быть настроен на ветку `main` и папку `/ (root)`. После загрузки дождись завершения публикации в Settings → Pages.
